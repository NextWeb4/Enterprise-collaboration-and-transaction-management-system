### 2026-11-02 后续模块并行开发

- **状态**：Accepted（用户明确授权）。
- **决定**：M0 验收未通过期间，可以与 M0 基础工程和验收并行开发后续业务模块，取代此前禁止进入 M1 的阶段限制。
- **边界**：M0 的未通过事实、验收标准和人工确认要求不变；并行开发不代表 M0 通过，也不授权使用或迁移真实业务数据。后续模块须独立验证，不能假定未落实的权限、存储或安全保证已具备；其余架构和安全约束继续有效。

- 此决策不表示范围过滤已实现；后续模块并行开发的授权另见上条决策。

### D-001 项目标识

- **状态**：Accepted
- **决定**：中文名“企业协同与事务管理平台”；英文名 Enterprise Collaboration & Office Management Platform；工程代号 `collab-office`。
- **影响**：最终品牌/域名/许可证仍需 Q-002。

### D-002 模块化单体

- **状态**：Accepted
- **决定**：一个 Node/Fastify 进程 + 一个 React SPA + 一个 LMDB 环境 + 本地文件目录；普通进程启动；内部按 Identity/Organization/Project/Task/Workflow/Document/Calendar/Notification/Analytics/Audit 分模块。
- **理由**：单组织、单机、500 用户；避免微服务/分布式复杂度。
- **复审**：需要多实例/独立扩缩容时重新架构。

### D-003 文档中心完整范围

- **状态**：Accepted（由 2026-10-31 任务指令确定）
- **决定**：文档中心按完整业务需求规划（文件管理、分类标签、搜索、权限、版本）；不采用 人为最小闭环 人为拆分。
- **影响**：R1 纳入完整文档中心核心；开发顺序可后置，但不是功能缩减。

### D-004 单组织，无 organization_id

- **状态**：Accepted（由任务指令确定）
- **决定**：单组织部署；无多租户、无组织切换、无 `organizationId`；组织资料为单例 `org_profile`。
- **理由**：需求明确单组织；去掉隔离字段与租户复杂度。
- **代价**：未来多组织需重构；当前不承诺。

### D-005 本机 Node + 静态 SPA，无 Docker

- **状态**：Accepted
- **决定**：Node 进程同时提供 API + 构建后的 SPA；单端口；普通 Windows 进程方式启动/停止（终端/启动脚本），不注册 Windows 服务；默认仅监听 127.0.0.1；无 Docker/K8s。
- **理由**：部署限制；降低运维。
- **代价**：无容器编排；需自建服务/日志/防火墙。

### D-006 LMDB 作为首选存储

- **状态**：Accepted（人工决策 2026-10-31）
- **决定**：`lmdb@3.5.9`，`encoding:'json'`，`maxDbs:128`，`mapSize:2–4GB`。
- **依据**：项目外原型通过 CRUD/事务/100 并发读改写/2 进程写/崩溃恢复/索引重建/50k 任务测试；详见 [嵌入式存储评估](../05-research/embedded-storage-evaluation.md)。
- **代价**：原生模块；OpenLDAP 2.8；无 repair；单写者；不适合网络盘。
- **备选**：ClassicLevel（需单写队列；不采用）。 

### D-007 JSON 文档 + 独立索引子库

- **状态**：Accepted
- **决定**：每实体一个命名 DB；JSON 文档；索引独立 DB；索引可重建。
- **理由**：避免单 JSON 文件；可读/可迁移；查询走索引。
- **代价**：唯一约束/引用完整性/索引维护自研。

### D-008 Repository / UnitOfWork / StorageEngine 抽象

- **状态**：Accepted
- **决定**：业务模块只依赖接口；LMDB 适配器唯一实现；关键写操作在 UnitOfWork 事务内。
- **理由**：可替换存储、可测试、防止模块直接访问 `data.mdb`。
- **禁止**：模块自行 `open()` LMDB、直接读写文件、无事务多步写。

### D-009 禁止 SQL/ORM/数据库服务

- **状态**：Accepted（最高约束）
- **决定**：不使用 PostgreSQL/MySQL/MariaDB/SQLite/SQL Server/Oracle；不使用 Prisma/TypeORM/Sequelize/Drizzle。
- **理由**：任务边界。
- **影响**：数据模型、索引、事务、迁移、测试全部改为 KV 方案。

### D-010 会话使用 LMDB + Cookie

- **状态**：Accepted
- **决定**：随机 token，LMDB 存 SHA-256；Cookie HttpOnly/SameSite=Lax（本地 HTTP 不设 Secure）；支持撤销/过期。
- **理由**：可撤销/可审计；同源 SPA 无需 JWT。

### D-011 Argon2id

- **状态**：Accepted
- **决定**：Argon2id；参数校准；登录限流/锁定。
- **理由**：内存硬，抗 GPU。

### D-012 RBAC + 数据范围 + 项目角色 + 文档 ACL

- **状态**：Accepted
- **决定**：单组织内保留角色权限、self/department/department_tree/all、项目角色、文档 ACL、菜单/API 权限、审计。
- **理由**：单组织不等于所有人看所有数据；需要最小权限。
- **代价**：权限组合复杂；统一 AuthorizationService + 矩阵测试。

### D-013 顺序单审批人审批引擎

- **状态**：Accepted（R1）
- **决定**：模板版本快照 + 实例 + 步骤 + 追加记录；顺序单审批人；通过/驳回/撤回/管理员转交；不支持会签/或签/条件分支/委托。
- **理由**：五类申请 R1；BPMN 过重。
- **存储**：一个 LMDB 事务内更新申请/实例/步骤 + 追加记录 + 通知/审计。
- **复审**：>30% 申请需要复杂路由。

### D-014 审批/审计哈希链

- **状态**：Accepted
- **决定**：全局审计链 + 审批实例内链；只追加。
- **理由**：检测删除/篡改；比普通 append-only 强。
- **边界**：不能防拥有 OS 管理员权限的人重写整库；需 ACL/审计。

### D-015 本地文件系统 + SHA-256 内容寻址

- **状态**：Accepted
- **决定**：文件存 `data/files/<sha256>`；元数据 `files`；文档版本/申请附件引用 fileId；上传补偿/启动对账。
- **理由**：无对象存储服务；去重/校验；文件协议简单。
- **代价**：文件与 KV 非原子；refCount/对账必须实现。

### D-016 不建设备份系统

- **状态**：Accepted
- **决定**：R1 不提供自动备份、异地备份、备份保留、备份加密、备份恢复 UI；不实现备份管理；不提供备份目录/任务/界面。
- **理由**：人工决策不建设备份系统；减少运行复杂度。

### D-017 单实例锁

- **状态**：Accepted
- **决定**：`data/locks/app.lock`；第二个 API 进程拒绝启动。
- **理由**：单写者/单进程设计；避免缓存/后台任务冲突。
- **复审**：多实例需共享存储/锁，重新架构。

### D-018 测试使用真实 LMDB 临时目录

- **状态**：Accepted
- **决定**：存储/API 集成测试用真实 LMDB + 临时目录；不 mock；测试崩溃/并发/索引重建。
- **理由**：存储行为是核心风险。

### D-019 UUIDv7 主键

- **状态**：Accepted
- **决定**：应用生成 UUIDv7；键空间/文档 ID 使用。
- **理由**：不暴露规模、时间有序、索引局部性好。

### D-020 schemaVersion + 迁移脚本

- **状态**：Accepted
- **决定**：`meta.schemaVersion` + 文档 `schemaVersion`；停机迁移；分块迁移；迁移后重建/校验索引/审计/文件；不提供自动备份/恢复。
- **理由**：无 SQL migration；必须可控升级。

### D-021 不引入 Redis/MQ/搜索集群

- **状态**：Accepted
- **决定**：首版无 Redis/消息队列/Elasticsearch；通知/审计同事务；报表实时查询。
- **理由**：单机 500 用户；减少组件。
- **复审**：明确异步/缓存/全文检索瓶颈。

### D-022 中文优先

- **状态**：Accepted
- **决定**：首版中文 UI；代码预留文案边界；不做运行时语言切换。
- **理由**：目标用户；减少 i18n 成本。

### D-023 首个管理员显式初始化

- **状态**：Accepted
- **决定**：无默认 admin/123456；CLI/初始化向导创建组织与管理员；已初始化拒绝覆盖。
- **理由**：安全。

### D-024 保留完整产品功能

- **状态**：Accepted
- **决定**：不因存储/部署改造删除项目、OA、组织、文档、日程、统计需求；R1/P1 只是交付顺序。
- **理由**：任务明确不得缩减。

### D-025 Windows 本机优先部署

- **状态**：Accepted
- **决定**：Windows 10/11 64 位；普通进程启动/停止；默认 127.0.0.1；需要局域网时显式改监听地址，仅受信网络；本地 HTTP，不引入反代/HTTPS。
- **理由**：目标环境；无 Docker/DB 服务。
- **兼容性**：Linux/macOS 理论可行，但未验证；不承诺。

### D-026 LMDB 许可证

- **状态**：Proposed（待法务/人工）
- **决定**：`lmdb` 包 MIT；LMDB 核心 OpenLDAP 2.8；LZ4 BSD-2；保留声明。
- **风险**：OpenLDAP 许可证需法务确认；不接受则回退 ClassicLevel/其他。

### D-027 首版不启用 LMDB 加密

- **状态**：Accepted（R1）
- **决定**：不实现应用层静态加密；不启用 `encryptionKey`；依赖操作系统/磁盘自身的访问控制（不在本项目范围）。
- **理由**：密钥管理/恢复未验证；避免误以为安全。
- **复审**：设备丢失/合规要求提高时评估。

### D-028 数据目录本地化

- **状态**：Accepted
- **决定**：`data/` 必须本地 NTFS/SSD；禁止 SMB/NFS/OneDrive/同步目录；启动检查/警告。
- **理由**：LMDB 内存映射/锁语义不适合网络盘。

### D-029 索引可重建

- **状态**：Accepted
- **决定**：索引是派生数据；提供 `rebuild-indexes`；维护模式；重建后校验计数/样本。
- **理由**：索引损坏可恢复；不把索引当数据源。

### D-030 无多组织/无外部访客

- **状态**：Accepted
- **决定**：首版不做多组织、组织切换、外部访客协作。
- **理由**：单组织边界；避免权限/数据模型复杂化。

### 2026-11-02 项目短键历史保留

为防止软删除项目后同短键重用导致历史任务编号冲突，开发中采用保守方案：项目短键永久保留，创建时在事务中检查包含已删除项目的主库；不迁移数据库或改变现有文档格式。原“仅未删除项目唯一”的规划由此实现决策取代；该方案并非用户单独确认的业务选择。
