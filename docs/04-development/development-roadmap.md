# 开发路线图

> 文档状态：Draft for Review  
> 版本：0.2.0  
> 日期：2026-10-31  
> 估算：16 周（单人全职 + AI 辅助，含缓冲）  
> 说明：这是估算区间，不是承诺；范围变更必须重估。  
> 架构：单组织、无 SQL/ORM/数据库服务、无 Docker、LMDB + 本地文件。

## 1. 阶段

```text
G0 架构重构审查
  ↓（人工批准）
M0 基础/存储/身份         Week 1–3
M1 项目/任务              Week 4–6
M2 OA/工作台              Week 7–9
M3 组织/系统/文档         Week 10–13
M4 硬化/部署/试点         Week 14–16
```

## 2. 里程碑

| 里程碑 | 周期 | 目标 | 退出条件 |
|---|---|---|---|
| G0 | 当前 | 重构审查 | 确认 LMDB/本地运行等问题 |
| M0 | 3 周 | 可登录、可存储、可审计骨架 | 事务/崩溃/索引测试；CI 绿 |
| M1 | 3 周 | 项目/任务闭环 | 项目 E2E；并发编号 |
| M2 | 3 周 | OA/工作台闭环 | OA E2E；并发审批/附件 |
| M3 | 4 周 | 组织/系统/完整文档中心 | 权限矩阵；文档 E2E |
| M4 | 3 周 | 可运行/可验收 | 全部验收门禁 |

## 3. M0：基础、存储、身份（3 周）

- pnpm workspace、TS strict、Vite/React 壳、Fastify。
- LMDB StorageEngine/Repository/UnitOfWork/索引注册/SchemaRegistry。
- 数据目录、单实例锁、初始化向导、配置。
- 用户/会话/角色/权限/审计框架。
- 健康检查、日志、verify/rebuild 脚本骨架。
- 登录/改密/限流/安全头/CSRF。

**退出**：

- 登录闭环；
- CRUD/唯一索引/事务回滚/100 并发计数器/崩溃恢复/索引重建测试；
- 无 SQL/ORM/Docker；
- CI 全绿。

## 4. M1：项目与任务（3 周）

- 项目/成员/状态、任务/编号/看板/进度/评论。
- LMDB 索引/唯一约束/项目序号事务。
- 工作台项目部分。

**退出**：项目闭环 E2E；100 并发任务编号唯一；看板并发 409；权限矩阵。

## 5. M2：OA 与工作台（3 周）

- 五类申请、附件、模板/版本、实例/步骤、审批记录/哈希链。
- 通过/驳回/撤回/转交；通知；待我审批。
- 工作台五模块。

**退出**：OA 闭环 E2E；并发审批只成功一次；文件一致性；工作台口径。

## 6. M3：组织、系统、完整文档中心（4 周）

- 组织/部门/员工/岗位/角色/权限。
- 用户/登录记录/操作日志/系统配置。
- 文档：上传/下载/归档、分类、标签、搜索、ACL、版本。
- 文件协议/对账；项目文档继承。
- 权限矩阵/有效权限预览。

**退出**：权限闭环；文档闭环；IDOR；审计覆盖。

## 7. M4：硬化、部署、试点（3 周）

- 崩溃/索引重建/断电演练。
- 性能 50k/100k；安全测试；E2E；移动端。
- 普通进程启动/停止；默认本机 HTTP；局域网显式开放。
- 试点与缺陷修复。

**退出**：验收全过；无 P0/P1；本机启动/停止/索引重建完成。

## 8. 关键路径

```text
M0 存储/身份
  ├─→ M1 项目/任务
  ├─→ M2 OA/工作台
  └─→ M3 组织/文档
        └─→ M4 验收
```

风险路径：

1. 存储抽象/事务不牢 → 全部返工。
2. 文件一致性最后做 → 数据不一致。
3. 存储事务/崩溃恢复最后做 → 无法验收。
4. Windows 原生模块/服务问题 → M0 阻塞。
5. 文档中心被误缩减 → 违反产品范围。
